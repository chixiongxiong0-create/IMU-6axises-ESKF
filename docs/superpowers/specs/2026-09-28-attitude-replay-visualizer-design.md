# IMU 姿态回放可视化设计

日期：2026-09-28。状态：待用户审阅。

## 目标与边界

为本仓库增加一个本地 Python 桌面测试工具，读取已有 `imu_replay` 输出的姿态 CSV，播放三维机体姿态及参考系坐标轴。单路模式显示一条轨迹；对比模式读取两条轨迹，可在左右双视图与同一场景叠加视图之间切换。它用于观察和对比算法输出，不替代数值验收或硬件真值测量。

第一版仅从 CSV 读取，不实现串口、网络或共享内存实时接收。数据输入层与时间轴、绘制层分离，为以后增加实时姿态源保留接口。使用本机现有 Python 环境安装 `PyVista`、`PyVistaQt`、`PySide6`，不创建虚拟环境。不得改变现有 C 库或其 CSV 输出格式。

## 输入契约

默认输入为 `imu_replay` 当前输出的精确列：`timestamp_ns,qw,qx,qy,qz,accel_weight,fusion_mode,health_flags,status`。至少一行数据；对比模式需要两份 CSV。解析器要求表头精确匹配、时间戳为非负 `uint64` 且严格递增、四元数分量为有限数、范数非零。逐行归一化四元数；拒绝坏行并给出文件名与行号，不静默跳过。`accel_weight` 必须是 [0,1] 内的有限数，后三个状态字段是 `uint32`；在画面上显示状态、融合模式和健康标志。首版不把这些字段解释为物理真值。

时间轴使用整数纳秒，避免大纪元时间戳转浮点造成精度损失。单路范围为其自身首尾时间。对比范围取两路时间范围的并集；每个显示时刻分别定位各自不晚于该时刻的最近有效样本，且只在该样本与时刻的间距不超过最大显示保持时间时显示。每条轨迹默认保持时间为相邻时间戳正差的中位数的两倍，上限 100 ms；单样本轨迹只在其精确时间戳显示。超限或时间范围外明确显示“无数据”，不以旧姿态冒充同步结果。拖动定位采用同一规则。对比图仅比较姿态，不从两份 CSV 推断空间位置或共同物理起点。

## 坐标与三维呈现

与 C 库一致：机体系 FRD（前、右、下），导航系 NED（北、东、下）；输入 `q_nb` 是标量在前、将机体系转到 NED 的 Hamilton 四元数。PyVista 场景使用 NED 物理轴；屏幕摄像机提供明确的默认视角与轴标签，不把屏幕向上误称为 NED 的向上。固定参考轴和随体轴用不同样式，轴色及标签保持一致。机体用带机头方向标记的简化刚体表示，不暗示实际载具外形或位置。四元数直接生成 3×3 旋转矩阵作用于机体和随体轴，不经欧拉角。

左右模式用两个并排的 PyVista/Qt 3D 视图，在两个视图中显示同样尺度、参考轴和预设摄像机方向；用户可以分别旋转视角，并可一键恢复共同预设视角。同场景模式在一组固定 NED 轴上以不同颜色与少量固定横向偏移显示两台机体，避免完全重合；偏移只是显示排版，不代表估计位置。标签说明颜色和偏移含义。窗口切换布局时保持当前播放时刻与速度。

## 播放与交互

Qt 主窗口包含文件选择/命令行文件参数、模式切换、播放/暂停、进度拖动、播放速度选择和当前时间文本。播放时以单调墙钟计算目标回放时刻，按 CSV 时间戳取样；渲染按界面定时器限频，不试图绘制全部 485 Hz 帧。播放速度至少覆盖 0.25×、0.5×、1×、2×、4×。暂停及拖动精确定位，拖动结束保持暂停/播放原状态。到达范围末端时停在最后时刻并暂停；不自动循环。窗口关闭时释放渲染资源。

对于 `status` 非 OK 或健康标志非零的行，仍可显示其姿态以供诊断，但须用醒目状态文字标识，不能呈现为健康测量。CSV 未包含 `attitude_epoch_ns` 或 `initialized`，因此首版只能按其 `timestamp_ns` 时间轴回放，并明确标注这是主机参考时刻而不是已经补偿的物理姿态时刻；不得凭缺失字段推断初始化状态。若未来 CSV 扩展新时间字段或实时源，必须显式版本化输入适配器。

## 组件与错误处理

1. **CSV 适配器**：独立于 Qt/PyVista，解析、校验并返回不可变的时间戳、四元数和状态序列。未来实时输入适配器应实现相同的样本访问边界。
2. **回放控制器**：维护单一整数纳秒播放位置、速度、暂停状态，负责两路时间定位和无数据判定；不依赖渲染器。
3. **场景渲染器**：负责静态 NED 轴、机体/随体轴 actor 更新、相机和布局；只消费控制器给出的姿态或无数据状态。
4. **Qt 应用入口**：文件加载、控件、错误提示和渲染计时。依赖导入失败时给出清晰的安装提示，不改写输入文件。

首版不保存视频，不开发网络协议，不修改 `imu_replay`，不新增算法精度门限。安装依赖只在实施阶段进行，遵循用户要求直接使用本地 Python 环境。

## 验证与验收

- 单元测试不启动 GUI：CSV 表头/数值/时间异常、四元数归一化、FRD→NED 旋转、时间定位、最大保持时间、并集边界、播放速度和到末端暂停。
- 用现有 `tests/data/replay_smoke.csv` 通过 `imu_replay` 生成输出，再加载可视化工具，确认单路回放；另用受控的第二条姿态轨迹验证左右与叠加两种模式。
- 在本机图形会话人工检查：静止单位四元数、已知正向单轴旋转、参考轴标签、相机恢复、播放/暂停/拖动/变速，以及缺失数据/退化状态提示。图形无法运行的无头环境只报告未完成此项，不声称视觉验证通过。
- 文档提供本地 Python 的安装和启动命令、CSV 契约、两种布局示例、显示时间语义及限制。现有 C 测试不应因新增 Python 工具发生变化；现有已知 `scenarios` 峰值失败不归因于可视化工具。
